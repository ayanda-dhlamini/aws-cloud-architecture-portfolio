# AWS Cloud Architecture Portfolio

Author: Ayanda Dhlamini

Welcome to my AWS Cloud Architecture Portfolio.

This repository contains a growing collection of cloud architecture projects, infrastructure implementations, and serverless solutions built using Amazon Web Services.

The purpose of this portfolio is to showcase practical experience designing scalable, secure, and automated cloud environments.

## Architecture Categories

### Serverless Architectures
Projects demonstrating event-driven and serverless solutions.

### Infrastructure Architectures
Projects focused on scalable and highly available cloud infrastructure.

### Networking Architectures
Cloud networking designs using Amazon VPC and secure routing.

### Security Architectures
Identity and access management and security design patterns.

## Featured Projects

### AI Document Processing Platform (Serverless)
A serverless pipeline that extracts structured data from procurement and compliance documents. Data at rest stays in `af-south-1` for POPIA, and processing runs in `eu-west-1` using Textract and Amazon Bedrock. Includes architecture decision records and a POPIA design review.
[View project](./serverless-architectures/ai-document-processing-platform)

### cPanel Hosting Migration to Amazon Lightsail (Infrastructure)
Migration of 61 cPanel accounts to AWS Lightsail, including incident response to a pre-existing malware compromise on the source server: 8 malware families identified, ~23,500 injector files removed, and all accounts live and verified clean. Includes a cleanup runbook and architecture decision record.
[View project](./infrastructure-architectures/lightsail-cpanel-migration)
